# 药准时后台管理原型 —— 制作简报

> 给原型构建者：依据《UI 设计规范》V1.0（`~/workspace/your_files/medontime-ui-design-spec/medontime-ui-design-spec.pdf`）
> 线框 W06（后台 Dashboard）、W07（后台成员详情）与《后台管理平台功能需求分析》V1.3。
> 演示数据均为占位；与用户端原型（slug space）相互独立。

## 目标

后台管理员管理平台的**可点击高保真原型**，面向运营 / 客服 / 药品审核员 / AI 服务管理员。
纯前端演示数据，无需后端。

## 设计依据（必须遵守）

- 视觉：**深色侧边栏 + 信息密度型**中后台布局，Ant Design 设计语言；主色医嘱绿 `#0B6B4F` 作点缀
- 后台主题范围：规范明确后台**不开放暖阳橙**；提供浅色/深色两种即可
- 冻结组件复用：成员切换器概念对应为「账号-成员树」视图；AI 免责条在 AI 相关页保持固定样式
- 敏感信息治理：病历/用药数据默认脱敏展示，点击查看需二次确认并记"查看留痕"提示条

## 页面清单（8 页，左侧导航）

1. **Dashboard**：核心指标卡（用户总数、今日提醒量、整体依从率、待办事项数）；待办列表（药品待审核 X、AI 抽检待处理 X、授权争议 X）；7 日依从率趋势图（占位折线图）
2. **用户管理**：用户列表（搜索：姓名/手机号/状态；列：用户ID、姓名、手机号脱敏、注册日期、状态）；点击行进详情：基础信息、绑定微信、账号状态操作（冻结/解冻）、注销信息
3. **成员详情**（账号-成员树视图）：成员档案、病历（脱敏+查看留痕）、用药计划、**委托照护授权管理**（授权列表：照护人×成员、L1/L2/L3 档位、一键回收按钮）、AI 分析记录
4. **药品维护**：药品列表（通用名、品牌、生产企业、状态）；**审核流演示**：待审核药品 → 通过/驳回（含驳回理由弹窗）→ 状态实时变更；新增药品（表单占位）
5. **提醒规则与通知**：提醒策略配置（提前量、重复次数、升级规则）；通知模板列表（三语页签展示）；发送记录查询
6. **AI 服务管理**：模型配置（主备、灰度开关、一键全局停用）；提示词模板版本列表（红线段落锁定标识）；Token 成本统计；**安全审核队列**：待抽检 AI 输出 → 标注通过/有风险（有风险则冻结会话演示）
7. **运营看板**：用户增长、提醒到达率、依从率对比（图表占位）
8. **系统管理**：管理员列表、角色权限矩阵（RBAC）、操作日志（带 diff 摘要占位）

## 核心可走查流程

- A：Dashboard 待办 → 药品审核 → 通过 → 待办数减一
- B：用户管理 → 某用户 → 成员详情 → 授权管理 → 对某保姆授权点"一键回收" → 状态变已回收 + 审计提示
- C：AI 服务管理 → 安全审核队列 → 抽检一条 → 标"有风险" → 会话冻结横幅

## 验收标准

- 左侧导航 8 页全部可达，无死链；表格行点击有反馈
- 三个核心流程全程可走完，状态变化实时可见
- 深色侧边栏 + 浅色内容区；敏感字段默认脱敏
- 无真实患者信息；控制台无报错
