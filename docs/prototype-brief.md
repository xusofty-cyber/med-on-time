# 药准时高保真原型 —— 制作简报

> 给原型构建者：本简报依据已冻结的《UI 设计规范》V1.0（`~/workspace/your_files/medontime-ui-design-spec/medontime-ui-design-spec.pdf`）
> 与《用户端功能需求分析》V1.3 编写；演示数据均为占位。

## 目标

Web 用户门户 + 微信小程序核心流程的**可点击高保真原型**，用于评审走查。纯前端演示数据，无需后端。

## 设计依据（必须遵守）

- 主色：医嘱绿 `#0B6B4F`；中国区医疗 App 审美：干净可信、留白、圆角卡片
- 4 套配色主题（清新青绿 / 沉稳藏青 / 暖阳橙 / 暗夜）× 标准/长辈关怀模式，原型内可实时切换验证
- 三语：简体中文（默认）/ 繁体中文 / 英文，原型内可切换验证（至少中英，繁体尽量）
- 线框参考：W01 移动首页、W02 全屏提醒、W03 建计划、W04 AI 助手、W05 小程序首页、W08 Web 桌面总览、W09 Web 移动响应式
- 冻结组件：成员切换器、代操作横幅、AI 免责条（固定样式）
- 适老化：长辈模式正文 ≥18pt、高对比、大触控目标

## 页面清单

### Web 端（响应式：桌面多栏 / 移动单栏自适应，窗口缩放即切换）

1. **今日用药**（默认首页）：顶部成员切换器；时间轴列出今日待服药品（药名、剂量、时段、餐前/餐后标签）；每条目三个动作：已服 / 稍后 / 跳过；点击后状态实时变化并计入今日进度环
2. **用药计划**：计划列表（进行中/已完成）；「新建计划」走五步：选成员 → 选药（搜索+扫码占位） → 用量频次 → 疗程与提醒 → 确认页
3. **AI 健康助手**：会话界面；顶部固定免责条（"AI 健康助手仅供参考，不能替代医生诊断"）；预置示例问答（病历解读、症状分析各一）；输入框演示流式回复（打字机效果）
4. **家庭**：成员卡片（父亲/母亲/自己，含头像占位、关系、用药数、今日依从率）；照护授权状态展示
5. **我的**：主题切换器（4 套实时换肤）、语言切换（简/繁/英）、长辈关怀模式开关、退出登录占位

### 小程序端（手机框内展示，与 Web 并列入口切换）

1. **首页**（W05）：今日用药卡片、一键打卡
2. **AI 助手**：卡片式分步问答演示
3. 底部 Tab：首页 / 计划 / AI 助手 / 我的（页面可复用 Web 端简化版）

## 演示数据（占位）

- 成员：自己（32 岁）、父亲（65 岁，高血压）、母亲（62 岁，糖尿病）
- 药品：苯磺酸氨氯地平片 5mg（每日一次 早8点 餐后）、二甲双胍片 0.5g（每日两次 早晚餐后）
- 今日时间轴：3 条待服，其中 1 条已服、1 条待打卡、1 条稍后

## 验收标准

- 所有按钮可点击且有反馈；页面间导航完整无死链
- 主题切换整站实时换肤无闪白；语言切换文案完整替换
- 桌面端缩到移动宽度自动切换单栏布局；小程序保持手机框
- 不出现真实患者信息；AI 页免责条常驻可见
