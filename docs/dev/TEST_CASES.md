# 测试用例与验证记录（2026-10-23 首轮全量验证）

> 口径：状态分四种——**已验证通过**（有真实运行证据）、**已验证缺陷→已修复**（缺陷曾复现，修复后复测通过）、**部分验证**（代码路径确认 + 局部实测，端到端受外部条件限制）、**未执行**（附原因）。验证手段：浏览器实测（真实页面操作）/ API 探针（线上接口直调）/ DB 核对 / 静态代码核对。执行环境：生产（mot.ulife.vip / admin.ulife.vip，2026-10-23）。
