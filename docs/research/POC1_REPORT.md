# POC-1 报告：免费药品数据源抽检（200 个常用药）

> 版本：V1.0（2026-10-20）| 状态：已完成，待评审
> 前置文档：《技术预研报告》V1.1（零预算版）§6 POC-1
> 约束：免费平台、无 GPU、不使用任何需要商业授权的接口；仅使用免费公开数据源。
> 原始数据与脚本：`~/workspace/medontime-poc1/`（数据准备报告、200 药清单、三份分析 JSON、五个脚本均可复现）。

---

## 1. 方法与判定标准

三层验证：

1. **全量自动化统计**：候选数据集解析、字段覆盖率、重复率统计（脚本统计，可复现）。
2. **200 药清单命中**：200 个常用药（16 类，慢性病用药 68%）在各候选库中的说明书命中率。
3. **内容准确性交叉核验**：从 200 药中分层抽 15 个样本（降压/降糖/调脂/抗栓/消化/呼吸/解热镇痛/甲状腺/抗过敏），取 CPM 记录的关键字段（用法用量、禁忌、不良反应）与**独立公开说明书来源**（39 药品通等，逐药记录来源 URL）逐条对照，结论分一致 / 次要差异 / 关键差异三级。

判定标准（预研报告 V1.1 预设）：关键字段准确率 ≥ 99%；相互作用覆盖率 ≥ 90%。

## 3. 说明书层：CPM-DDI-KG 定为主源

- 规模：12,087 条药品记录、25,738 份说明书条目、8,988 个通用名（数据抓取至 2026-10-10，时效为候选最新）。
- LICENSE 原文实读为 **CC BY 4.0**，署名后可商用——免费源里唯一同时满足「覆盖 + 正文 + 可商用」的数据集，**定为说明书层主数据源**。
- 未命中 4 药（甲基多巴、艾塞那肽、阿普唑仑、佐匹克隆）：走人工录入 + 双人核验流程补录。
- 英文名覆盖仅 12.2%：三语方案的英文药名与 INN 对照继续走 RxNorm / openFDA 补齐（与预研结论一致）。
- 注意：24.1% 的药品记录说明书列表为空，入库时须按「有说明书条目」过滤并计数监控。

## 4. 内容准确性：3 处关键差异与 5 类可自动检测的缺陷模式

15 药核验汇总：一致 4（氨氯地平、华法林、对乙酰氨基酚、沙丁胺醇）；次要差异 8（核心剂量与频次无出入，差异在禁忌详略、版本表述、年龄段划分）；关键差异 3：

1. **阿司匹林肠溶片**：服药时机与对照（原研拜阿司匹灵说明书）直接相反——CPM 记录为「饭后服用、不可空腹」，原研为「饭前空腹服用」。根因是不同厂家说明书口径不同：**餐前/餐后类字段必须按具体产品入库，禁止按通用名合并**。
2. **奥美拉唑钠肠溶片**：该记录不良反应字段整段为空；且禁忌将同类说明书的「肝肾功能不全者慎用」写成「严重肾功能不全者禁用」，口径升级。
3. **左甲状腺素钠片**（雷替斯 H20110178）：用法用量只剩「详见表 1/表 2」索引、无剂量数值（表格未被抓取）；禁忌疑似串入优甲乐版本文本，且漏掉「心衰/快速型心律失常」一条。

缺陷模式归纳（全部可自动检测，是入库质检管线的规则来源）：

| # | 模式 | 样例 | 自动检测规则 |
|---|---|---|---|
| P1 | 剂量表格未抓取、只剩索引文字 | 左甲状腺素 | 用法用量含「详见表/详见说明书」且无剂量数值 → 拦截人工处理 |
| P2 | 关键字段整段为空 | 奥美拉唑不良反应 | 关键字段为空 → 拦截；与全量非空率交叉监控 |
| P3 | 跨产品文本串扰 | 左甲状腺素禁忌 | 同通用名多产品文本相似度异常 / 禁忌与适应症矛盾 → 标记复核 |
| P4 | 警示语误置入禁忌 | 美托洛尔「运动员慎用」 | 禁忌字段命中警示语词表 → 自动移位到注意事项 |
| P5 | 规格字段错误 | 布洛芬混悬液规格 25ml:0.2g（登记应为 0.5g） | 规格与批准文号登记信息比对 → 不一致拦截 |

另有入库口径要求（数据准备阶段发现）：按通用名粗匹配会优先撞上**复方制剂**（如「氨氯地平」先命中氨氯地平阿托伐他汀钙片），管线必须做**单方优先 + 盐型归一化**（苯磺酸/盐酸/硫酸氢等前缀剥离）。

## 5. 相互作用层：当前免费源不达标，定替代打法

- DDInter 覆盖最好（79.5%）但未达 90% 门槛，且 CC BY-NC-SA **不可商用**、22.4% 记录分级 Unknown、下载数据无应对文本 → **仅作内部核对参考，不入库、不对用户展示**。
- CPM 自带 mutualEffect 表以中成药/OTC 组合为主，西药配伍覆盖 13.0% 且无分级 → 不可用。
- **替代打法（定版）**：① 以 CPM 说明书「相互作用」字段（非空 78.7%，含大量模板文本）做结构化抽取（药对 + 结论）作为基础层；② ONC 高优先级相互作用清单覆盖高危组合硬校验；③ 抽取不确定的组合进**人工药师审核队列**，未审核不展示；④ 高危组合零漏报优先于覆盖率（与 POC-3 标准衔接）。

## 6. POC-1 判定与处置

- **说明书层：有条件通过。** CPM-DDI-KG 定为主源；上线前必须建成第 4 节的质检管线（P1–P5 规则 + 单方优先/盐型归一化 + 4 药人工补录），质检拦截项清零后方可入库。
- **相互作用层：不通过（按现成免费源口径）。** 改走第 5 节替代打法，在 POC-3 中以「高危零漏报 + 一般组合覆盖率」重新验收。
- **许可结论**：生产数据只允许来自 CC BY 4.0 的 CPM 与官方公开数据（NMPA / RxNorm / openFDA / DailyMed）；DDInter 与 QASystem 数据严禁进入生产库。

## 7. 后续动作

1. 建入库质检管线（规则 P1–P5 + 匹配口径），对 CPM 全量跑一遍并输出拦截清单。
2. 4 个未命中药 + 质检拦截项走人工录入/复核（双人核验）。
3. 相互作用结构化抽取原型（说明书字段 → 药对），喂 POC-3 验收。
4. 英文名/INN 补齐管线（RxNorm / openFDA）并入药品库多语言字段（与 DB locale 待办衔接）。
