# 药准时 MedOnTime 技术预研报告

> 版本：V1.1（2026-10-20）| 状态：待评审
> 预研目标：探索可集成的**AI 问诊/对话系统**与**药品系统**（开源与商用），给出选型建议、分期集成路径与 POC 计划。
> **硬约束（用户 2026-10-20 确认）**：运行环境为免费平台，无 GPU 服务器，暂不做资金投入，**不使用任何需要商业授权的对接接口**。本报告所有选型均在此约束下给出；商业授权路径仅列为"未来可选升级"，不在当前范围。
> 边界声明：产品定位为 **AI 健康助手**（健康咨询 / 用药科普 / 报告解读 / 就医引导），不做疾病诊断结论；本报告所有候选系统的输出均须经过安全规则层约束后才能触达用户。

---

## 1. AI 问诊 / 对话层

### 1.1 开源医疗大模型（用免费托管推理做 POC，暂不自托管）

无 GPU 服务器，故开源模型不做本地部署。POC 阶段使用免费托管推理：魔搭 ModelScope 免费推理额度、HuggingFace 免费推理额度、Kaggle / Colab 免费 GPU（Kaggle 每周约 30 小时免费 GPU，可跑 7B 量化模型评测）。

| 模型 | 机构 | 规模 | 开源与许可 | 中文医疗能力 | 评估 |
|---|---|---|---|---|---|
| **华佗GPT-II (HuatuoGPT-II)** | 港中文深圳 / 深圳市大数据研究院 | 7B / 13B / 34B | 权重开源；官方声明**不可直接利用结果进行诊疗**；商用许可须单独核查 | 通过执业药师等考试；中文医疗基准领先 | **POC 首选**，7B 量化版走免费托管推理 |
| **京医千询** | 京东健康 | 全面开源（参数、数据构造、训练、评测代码） | 已宣布全面开源；商用许可须单独核查 | 背靠京东互联网医院真实问诊数据 | POC 第二候选 |
| 本草 BenTsao / 扁鹊 BianQue / DISC-MedLLM / DoctorGLM | 各高校 | 6B–13B | 开源 | 2023 年水平 | 规模小、停滞，仅作参考 |

结论：POC 只验证 **华佗GPT-II 7B（量化）** 与 **京医千询**；其余仅作架构参考。

### 1.2 免费档通用模型 API（P1 AI 基础版的实际落点）

在 RAG（药品库 / 说明书 grounding）+ 安全规则层约束下，免费档通用模型足以承担"健康助手"的问答任务（用药咨询、报告解读、风险提示），无需医疗专用模型即可起步。

| 模型 API | 免费政策 | 备注 |
|---|---|---|
| 讯飞星火 Spark Lite | 讯飞开放平台长期免费档 | 中文理解好，适合健康咨询场景 |
| 智谱 GLM-4-Flash | 智谱开放平台免费档 | 免费额度充足，可做主力备选 |
| DeepSeek API | 极低价（非免费，但成本可忽略） | 效果强，作为免费档不足时的兜底 |

> 免费档的额度、条款、数据留存政策在接入前逐项核查；所有调用走 AI 网关（已设计），模型可随时替换。

### 1.3 商用医疗大模型 API（暂不采用，未来可选）

讯飞星火医疗、百度灵医智惠、腾讯混元医疗、阿里健康医鹿等**需要商业授权 / 付费**，当前范围暂不采用；待业务验证后再评估。行业背景参考：全国已发布 352+ 个医疗大模型，模型过剩但跑通"部署—使用—付费"闭环的产品稀缺。

### 1.4 症状分诊引擎（不接入）

- **Infermedica**（波兰）：欧盟 MDR IIb 认证、1800+ 症状 / 900+ 疾病、约 94% 分诊准确率，但**企业级付费 + 境外服务器（数据出境风险）+ 器械认证不适用于中国**——三重否决，不接入。
- ApiMedic 等：能力弱，同样需付费，不接入。

结论：**不做正式分诊功能**。P2 以"免费档模型 + 安全规则"实现轻量风险提示与就医引导，不出分诊结论。

## 2. 药品系统层（零预算：只用免费公开数据源）

### 2.1 免费数据源（当前范围）

| 数据源 | 内容 | 接入方式 | 评估 |
|---|---|---|---|
| **NMPA 国家药监局药品数据** | 官方批准文号 / 上市药品信息 | 公开查询 | 权威基准，用于批准文号核验与数据清洗 |
| **开源药品说明书数据集**（GitHub 多个） | 中文药品说明书文本 | 下载 | 质量不一，**逐个核查开源许可**后再用；作为中文说明书打底 |
| **国家医保药品目录**（公开版） | 药品目录、医保分类 | 官方公开文件 | 辅助药品标准化与分类 |
| **openFDA** | 美国说明书 / 不良事件 / 召回（英文） | 免费 API（key 后 12 万次/天） | 英文对照与安全信号参考 |
| **RxNorm (NLM)** | 药名标准化 / INN 通用名对照 | 免费 API | 补齐三语方案中英文药品名与 INN 映射 |
| **DailyMed (NLM)** | FDA 说明书全文（SPL） | 免费下载 | openFDA 的补充 |
| **DDInter** | 药物相互作用数据库（开放获取） | 免费下载 | **相互作用的免费主力来源** |
| **ONC 高优先级相互作用清单** | 最高优先级药物警戒对 | 公开 | 覆盖核心高危组合，做兜底校验 |

### 2.2 商业数据源（暂不采用，未来可选）

丁香园用药助手（7 万+ 说明书授权）、药智数据、DrugBank（相互作用严重程度分级需付费授权）、聚合 API 市场（付费）——当前范围全部暂不采用；待业务验证、需要更高数据质量时再走商务。

结论：**P0 免费打底组合** = NMPA 核验 + 开源说明书数据集（核许可）+ 医保目录 + DDInter（相互作用）+ openFDA/RxNorm/DailyMed（英文与 INN）。数据库设计 V1.1 的药品库 schema 已预留说明书结构化字段与多语言字段，即插即用。

## 4. 许可、合规与风险清单（零预算版）

1. **开源模型许可**：华佗GPT-II、京医千询在任何商用前必须逐条核查开源许可；当前 POC 阶段仅限内部评测。
2. **开源数据集许可**：GitHub 说明书数据集逐个核查许可（是否允许商用、是否要求相同方式共享），保留核查记录。
3. **免费 API 条款**：免费档的额度上限、数据留存、服务可用性 SLA 在接入前逐项核查；关键链路做降级预案（模型网关已支持多模型切换）。
4. **数据出境**：不接入任何境外付费服务；openFDA / RxNorm 等为公开非个人信息数据，仅做后台数据整理，不上传用户数据。
5. **医疗器械注册**：不做正式分诊 / 辅助诊断功能，当前"健康助手 + 风险提示"定位可规避。
6. **药品功效表述**：AI 输出与药品介绍文案须符合广告法与药品管理法（不做疗效承诺），安全规则层强制约束。
7. **模型幻觉**：医疗问答必须走 RAG（药品库 / 说明书 grounding）；无依据回答一律转人工建议或拒绝回答并引导就医。

## 5. 推荐集成路径（零预算分期）

- **P0（免费数据打底）**：NMPA 公开数据核验 + 开源说明书数据集（核许可）填充药品库；RxNorm 做英文名 / INN 对照；DDInter + ONC 清单建相互作用基础表；i18n 药品多语言字段同步填充。
- **P1（AI 基础版上线）**：AI 网关（已设计）接免费档 API（星火 Lite / GLM-4-Flash）跑通全链路（RAG grounding、安全规则、审核）；同步用免费托管推理（魔搭 / Kaggle 免费 GPU）做华佗GPT-II 7B 与京医千询的 POC，对比效果 / 延迟；相互作用校验基于 DDInter 上线。
- **P2（增强）**：根据 POC 结果决定是否引入开源医疗模型做主力；引入知识图谱增强 grounding；分诊仍只做风险提示。
- **未来可选升级（不在当前范围）**：丁香园 / 药智数据授权、DrugBank 授权、商用医疗大模型 API、自托管 GPU。

与现有架构的对接点：`ai_model_config` 表已预留多模型路由字段；`ai_safety_rule` / `ai_output_review` 承接安全约束；药品库表承接说明书结构化字段；**不改已冻结设计**。

## 6. POC 计划（零预算）

### POC-1：药品数据打底
- 目标：验证免费数据源可用性。
- 方法：抽取 200 个常用药，用开源说明书数据集 + NMPA 核对关键字段（用法用量、禁忌、相互作用）准确率；DDInter 抽 100 组常用复方验证相互作用覆盖率。
- 通过标准：关键字段准确率 ≥ 99%，相互作用覆盖率 ≥ 90%，否则换源或加人工审核流程。

### POC-2：AI 对话模型选型（免费托管推理）
- 候选：华佗GPT-II 7B（量化，Kaggle/魔搭免费推理）vs 京医千询（免费托管）vs 免费档通用模型（星火 Lite / GLM-4-Flash + RAG）。
- 评测集：自建 120 题（药品咨询 40 / 报告解读 40 / 风险提示与就医引导 40），含 20 题安全红线题（必须拒绝或转介）。
- 指标：医学准确性（医生盲评）、安全规则拦截率（红线题 100%）、幻觉率、P95 延迟。
- 通过标准：准确性不低于免费档基线、安全拦截 100%、幻觉率 < 5%。

### POC-3：相互作用校验
- 方法：DDInter + ONC 清单 + 说明书禁忌字段三源交叉，100 组常用复方。
- 通过标准：高危组合零漏报；一般组合覆盖率 ≥ 90% 或明确人工药师审核兜底流程。
