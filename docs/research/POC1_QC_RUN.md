## 1. 管线口径

- **匹配口径**：通用名字段先清洗（剥说明书页眉污染、品牌名前缀）→ 盐型归一化（剥 18 种盐/酯前缀与 20+ 剂型后缀）→ 批准文号取核心码（如 H20051864）比对 → 入库选取按**单方优先**（复方制剂以名称口径识别：含「复方」或通用名为两个已知词干拼接）。
- **规则**（源自 POC-1 第 4 节缺陷模式，运行中新增 P6）：

| 规则 | 内容 | 分级 |
|---|---|---|
| P1 | 用法用量仅含「详见表/详见说明书」索引且无剂量数值（表格未抓取） | BLOCK |
| P2 | 关键字段为空（dosage / contraindications 为 BLOCK 级，其余 REVIEW 级） | BLOCK / REVIEW |
| P3 | 禁忌长文本（≥40 字）跨 ≥2 个不同通用名出现（串扰嫌疑） | REVIEW |
| P4 | 禁忌字段含警示语（如「运动员慎用」），应移至注意事项 | AUTOFIX |
| P5 | 规格为空/无数值；同一批准文号跨通用名（清洗后口径） | REVIEW / BLOCK |
| P6 | genericName 字段被说明书页眉文本污染（管线自动清洗留痕） | AUTOFIX |

分级含义：BLOCK 不得入库；REVIEW 人工确认后入库；AUTOFIX 管线自动修复后放行。

## 5. 管线迭代修正记录（v1 → v3，均有实测依据）

1. **撤销「同文号多规格」缺陷判定**：v1 误报 2,211 条；实测同一注册证覆盖多规格属正常登记形态（进口注册证尤甚，1,088 个文号多规格），v2 起仅计数不拦截。
2. **复方判定改口径**：v1 按成分字段分隔符判定，误报率 52%（成分原文含化学式、辅料与 HTML 残留，不可用）；v2 改名称口径后复方条目 13,408 → 1,720（6.6%）。
3. **新增 P6 并清洗通用名**：2,568 条 genericName 被页眉文本污染；清洗后唯一通用名从 9,619 收敛为 7,275，P5 跨通用名误报随之大幅下降。
4. **批准文号规范化**：原文带「国药准字/进口药品注册证号」等前缀，统一取核心码后分组比对才成立。

## 6. 遗留与后续

1. **P5 外部比对未做**：规格与 NMPA 登记的一致性需登记数据接入后补跑（布洛芬规格问题即属此类）；当前 P5 仅内部一致性口径。
2. **别名映射表**：前药名（替诺福韦二吡呋酯）、盐型（埃索美拉唑镁、草酸艾司西酞普兰类已部分覆盖）与商品名别名需人工建表，建后重跑可再收敛一批 REVIEW/无此通用名。
3. **优先处理队列**：200 药中的 2 个全拦截 + 4 个复核先行处理；11 个真缺失走人工录入 + 双人核验。
4. REVIEW 队列按通用名收敛后实际人工量为 1,313 个通用名（非 6,073 条），可按常用药优先分批消化。
5. 相互作用字段为空达 5,483 条（21.3%），与 POC-1 相互作用替代打法衔接：结构化抽取时以「有相互作用字段」的说明书为语料，无字段药品默认进人工审核队列。
