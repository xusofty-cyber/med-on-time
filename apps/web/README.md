# apps/web —— Web 用户门户

用户配置用药计划、查看提醒、服药打卡的 Web 端（React 18 + Vite + Tailwind，医嘱绿 #0B6B4F，端口 5174，`/api` 代理到后端 3000）。

- 同一套页面同时适配 **PC 桌面浏览器**与**移动端浏览器**（响应式：PC 左侧导航，移动端底部导航）
- 桌面特有：大屏家庭用药总览、批量操作台、打印用药清单、键盘快捷键（后续迭代）
- PWA（添加到主屏幕、离线打卡）为 P1，尚未接入

## 已实现（2026-10-23，按 docs/dev/API_CONTRACT.md 用户端接口）

路由为零依赖 hash 路由（`src/lib/router.ts`），状态为零依赖轻量 store（`src/lib/store.ts`），
请求统一走 `src/lib/api.ts`（信封解包、Bearer 注入、401 单飞刷新 + 重放、会话失效回登录页），
接口调用集中在 `src/lib/endpoints.ts`，DTO 类型在 `src/lib/types.ts`。

| 路由 | 页面 | 内容 |
|---|---|---|
| `#/login` | 登录 | 账号（手机号或邮箱）+ 密码登录、微信小程序扫码登录（待扫/待确认/自动发令牌换登）、忘记密码（邮箱验证码重置） |
| `#/register` | 注册 | 邮箱验证码注册与手机号免验证码直接注册双通道，注册后自动装载本人成员直达今日页 |
| `#/scan-login` | 扫码确认页 | 微信小程序扫码登录的 Web 端轮询与换发票据落地页 |
| `#/` | 今日提醒 | 当日时间线、打卡（clientRequestId 幂等）、稍后提醒（按 cycle 顺延）、跳过（可填原因）；30 秒轮询，到点横幅 + 标题闪烁 + 浏览器通知与桌面端桥同步（锁屏是否显示药名受成员设置 lockScreenShowDrugDetail 控制） |
| `#/members` | 成员管理 | 列表/新增/编辑/删除（上限 10 提示）、切换当前成员、关怀与强提醒设置（关怀模式、强提醒 strongAlertMode none/alarm/voice、cycle 预设 标准90/15·温和120/30·严格60/10、锁屏药品详情默认关） |
| `#/plans` | 用药计划 | 列表、新建/编辑（药品搜索选药/自建药品/拍照识药、多明细、剂量/频次/餐关系/疗程、剂量阶段、PRN 上限、存放位置/附加备注、周期覆盖与强提醒覆盖 strongAlertModeOverride）、暂停/恢复、变更史、删除；非 L3 授权成员只读 |
| `#/adherence` | 依从统计 | 周/月汇总卡（应服/实服/按时率/服药率/漏服/跳过）+ 月历热力视图 |
| `#/stock` | 库存 | 列表、过期/临近到期（30 天）/余量不足（约可服 <7 天）预警、库存调整（补货/手动/过期作废，走流水） |
| `#/ehr` | 健康档案 | 过敏档案（整体 PUT 保存）、服药后不适记录（关联服药事件可选）、紧急联系人 CRUD（上限 3）、**健康概况**（单条表单：血型/身高/体重/常去医院/病情摘要，正文加密存储） |
| `#/authorizations` | 照护授权 | 我授权的/授权我的、按手机号发起授权（L1/L2/L3、可设到期）、接受/拒绝/撤销（受限账号接受时拦截并提示） |
| `#/notifications` | 消息中心 | 站内通知列表/单条已读/全部已读、渠道偏好（短信须已验证手机号开启；微信订阅消息联动） |
| `#/settings` | 设置 | 账号资料、微信绑定状态、登录会话列表与逐个退出、注销申请（30 天冷静期规则说明与撤销申请） |

关怀模式：成员 care-settings 的 careMode 驱动 `html[data-care-mode='on']`，样式在 `src/index.css`
（字号放大、高对比深绿 ≥7:1、交互目标 min-height 56px）。
