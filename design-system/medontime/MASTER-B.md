# 主题 B — 临床极简（Clinical Minimalism）完整规范

> 事实源：`design-system/medontime/tokens.json`（本文件是该源的人类可读规范；取值冲突时以 `tokens.json` 为准）。
> 证据等级：**已定义 / 已测量 / 有依据的推断 / 未知**，全程不得混写。**本主题全部取值为“有依据的推断”**（来源：ui-ux-pro-max skill 草案，经审计缺陷 D1–D10 人工修正；对比度为 WCAG 公式实算），**不得标为已定义或已测量**，不得与主题 0 的实测值混写。
> 审计依据：`~/workspace/medontime-review/design-tokens-stage0-3-2026-10-25.md` §2.5、§4.4。用户定案（2026-10-25）：默认主题仍为主题 0（绿白）；主题 B 不替代默认主题。

## 0. 主题定位

- **面向**：Admin + PC 主推；**移动端不做**。
- **风格**：Minimalism & Swiss Style——冷白底、紧凑间距、圆角全部 0、无阴影、靠 1px 边框分层。
- **与主题 A 的关系**：同一套语义色名，取值/密度不同。除下表列出的底色/边框/字体/密度外，**其余色值与主题 A 相同**（审计 §4.4）。
- **与主题 0 的关系**：**替换关系，不是叠加**。`primary/action` 蓝色系替换主题 0 的绿色系；`destructive/warning/success-tint` 组复用主题 0 取值（已按 B 底色重算对比度，见 §1）。
