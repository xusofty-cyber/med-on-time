# 主题 A — 暖阳关怀（Warm Sunshine Care）完整规范

> 事实源：`design-system/medontime/tokens.json`（本文件是该源的人类可读规范；取值冲突时以 `tokens.json` 为准）。
> 证据等级：**已定义 / 已测量 / 有依据的推断 / 未知**，全程不得混写。**本主题全部取值为“有依据的推断”**（来源：ui-ux-pro-max skill 草案，经审计缺陷 D1–D10 人工修正；对比度为 WCAG 公式实算），**不得标为已定义或已测量**，不得与主题 0 的实测值混写。
> 审计依据：`~/workspace/medontime-review/design-tokens-stage0-3-2026-10-25.md` §2.5、§4.4。用户定案（2026-10-25）：暖白底 `#FFF9F2` 接受；默认主题仍为主题 0（绿白），主题 A 不替代默认主题，不与既有的长辈关怀模式合并（关怀模式是成员级设置驱动的字号/对比度放大，不是主题切换）。

## 0. 主题定位

- **面向**：用户端主推，面向长辈/家庭成员的日常用药提醒。
- **风格**：Soft UI Evolution——暖白底、疏朗间距、柔和单层阴影、圆角 8/12/16/999px。
- **与主题 0 的关系**：**替换关系，不是叠加**。`primary/action` 蓝色系替换主题 0 的绿色系；`destructive/warning/success-tint` 组复用主题 0 取值（已按 A 底色重算对比度，见 §1）。
- **与关怀模式的关系**：独立主题，与关怀模式并存。关怀模式（字号 ≥18pt、触控 ≥56px、对比度 ≥7:1）在主题 A 之上仍可叠加开启；叠加后的关怀配色（深绿 `#084C38` 等主题 0 关怀值）在主题 A 下是否改用蓝色系，**未证实**，留待组件任务裁决。
